# ทำไมเราขุดทะลุโลกไม่ได้ — คลิปอธิบาย 60 วินาที (สไตล์ Kurzgesagt)

สร้างด้วยสกิล `kurzgesagt-style-explainer`: Remotion 4, 1920×1080, 30 fps, ยาว 60.0 วินาที → `out/final.mp4`
ภาพทุกชิ้นวาดเองเป็น SVG/React (ไม่มีตัวละคร โลโก้ หรือภาพของ Kurzgesagt) เพลงและเสียงเอฟเฟกต์สังเคราะห์เองทั้งหมดด้วย `tools/synth_audio.py`

## สถานะ: ยังไม่มีเสียงพากย์
คีย์ ElevenLabs ยังไม่ได้ใส่ ตอนนี้จึงเป็นเวอร์ชันที่มี **ซับไตเติลภาษาไทยแทนเสียงพากย์** และจังหวะภาพใช้เวลา *ประมาณ* จากจำนวนตัวอักษร (`tools/make_timing.py estimate`)

เมื่อใส่คีย์แล้ว (เมนู environment ของ session → Edit → Network secrets, host `api.elevenlabs.io`, header `xi-api-key`):
```bash
export ELEVENLABS_VOICE_ID=<voice id>  ELEVENLABS_MODEL_ID=eleven_v3   # โมเดลที่พูดไทยได้
tools/tts_th.sh                       # → public/voice.mp3 + src/timing.json (source: elevenlabs)
npx remotion render DigThroughEarth out/final.mp4
```
ทุกช็อต ป้าย และเสียงเอฟเฟกต์ผูกกับวลีใน `src/timing.json` จึงซิงก์ใหม่เองอัตโนมัติ เมื่อมีเสียงจริงซับไตเติลจะปิดเอง (prop `captions`) และเพลงจะ duck ลงขณะพูด
ถ้าเสียงยาวเกิน ~57 วินาที ให้ตัดคำใน `narration.txt` (สกิลแนะนำว่าอย่าพึ่งการปรับ speed)

## ตรวจข้อเท็จจริง (ตัวเลขทุกตัวที่ใช้)
- เส้นผ่านศูนย์กลางโลก ≈ 12,742 กม. (รัศมีเฉลี่ย 6,371 กม.) — NASA Earth fact sheet
- หลุมเจาะโคลา (SG-3) ลึก 12,262 ม. เริ่มเจาะ 1970 ถึงความลึกสูงสุด 1989; อุณหภูมิก้นหลุม ~180 °C — บันทึกโครงการ Kola Superdeep Borehole
- 12.262 / 6,371 ≈ 0.19% → "ไม่ถึง 0.2%"
- แมนเทิลหนา ~2,900 กม. เป็นหินแข็งที่ไหลแบบพลาสติก (ไม่ใช่ลาวา) เคลื่อนที่ระดับเซนติเมตรต่อปี (พอๆ กับเล็บงอก ~3–4 ซม./ปี) — USGS
- แก่นชั้นนอก: เหล็ก-นิกเกิลเหลว หนา ~2,200 กม.; แก่นชั้นใน: เหล็กแข็ง รัศมี ~1,220 กม. — PREM / USGS
- อุณหภูมิแก่นชั้นใน ~5,000–6,000 °C (งานทดลองปี 2013 ประเมินใกล้ 6,000 °C); ผิวดวงอาทิตย์ ~5,500 °C (5,772 K) → "พอๆ กับผิวดวงอาทิตย์"
- ความดันที่ใจกลางโลก ~360 GPa ≈ 3.6 ล้านเท่าของความดันบรรยากาศที่ผิวโลก
- โครงสร้างภายในโลก (รวมถึงแก่นชั้นนอกเป็นของเหลว) รู้ได้จากคลื่นแผ่นดินไหว (เงาคลื่น S)

ข้อลดทอน: เปลือกโลกในภาพผ่าครึ่งวาดหนากว่าจริง (ถ้าตามสเกลจริงจะบางกว่าเส้น); รังสีคลื่นวาดเป็นเส้นโค้งเชิงสัญลักษณ์ ไม่ได้คำนวณการหักเหจริง

## สิ่งที่ยังไม่ดี / จะปรับต่อ
- ยังไม่มีเสียงพากย์จริง (รอคีย์) — จังหวะภาพตอนนี้เป็นค่าประมาณ
- ยังไม่มีใครได้ฟังมิกซ์เสียง (ผมฟังไม่ได้): เพลงและเอฟเฟกต์ควรมีคนฟังหนึ่งรอบ
- edge_density ยังต่ำกว่าอ้างอิงเล็กน้อย (0.044 vs 0.066) — เพิ่มลายเส้นละเอียดได้อีก
- ช็อตแมนเทิลช่วงแรกค่อนข้างโล่ง
